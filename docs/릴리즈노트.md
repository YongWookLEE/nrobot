# 릴리즈노트

변경이 생기면 위쪽에 새 판을 덧붙입니다.

## v0.1 — 임시 시연판 (작성 중, 2026-10-26)

기존 Windows 프로그램(v29.3)과 Flask 웹 1.0을 대체하는 첫 웹 시연판입니다. 계산식·번호 규칙과 결과물 모양은 기존과 같게 옮겼습니다.

### 포함 기능

- 공용 비밀번호 입장(서명 쿠키 30일 유지, 나가기). 비밀번호가 설정되지 않으면 아무도 들어갈 수 없습니다.
- 입장 후 처음 화면(랜딩페이지)과 견적 입력 화면.
- 견적서 5종: ① 부가세 표시, ② 부가세 미포함, ③ 비용 분리, ④⑤ 영업1·2팀 제품 견적.
- 출입통제 기준가격표(①②③)와 영업팀 제품가격표(④⑤)에서 품목 선택. 제품 줄은 가격표와 연동되며, 가격표가 바뀌면 화면을 열 때 갱신하고 바뀐 줄을 알립니다.
- PDF·Excel(수식 포함) 생성, 함께 저장 시 같은 견적번호.
- 견적번호 자동 발급·직접 입력·중복 거부, 생성 성공 시에만 번호 기록.
- 입력 자동 저장·복원, 임시 저장 2개 버튼, 담당자 휴대폰 수정값 기억.
- 휴대폰 화면 폭에서 사용 가능.

### 제외한 기능 (기존 웹 1.0에 있었거나 향후 범위)

- 개인 계정 로그인, 관리자 화면(가격표 업로드·백업, 담당자 관리). 가격표·담당자 변경은 다시 배포로 합니다.
- 서버의 입력 초안·견적 결과 보관, 견적 이력 검색.
- 서버 DB 기반 견적번호 발급(전체 사용자 간 중복 방지).
- 사전원가표 기능.

### 알려진 제한

- **견적번호는 브라우저별로 발급**하므로 다른 PC·브라우저끼리 번호가 겹칠 수 있습니다.
- **맑은 고딕 라이선스 검토 필요**: ①②③ PDF에 맑은 고딕을 넣어 서버에서 만듭니다. 정식 운영 전에 회사가 판단해야 합니다.
- **Vercel 무료(Hobby) 요금제 조건**: 개인·비상업 용도 조건이 있고, 함수 실행 시간·응답 크기(약 4.5MB) 한도가 있습니다. 정식 운영 시 유료 전환을 검토합니다.
- 입장 쿠키 서명 키가 비밀번호 자체이므로, 비밀번호는 길고 무작위로 정해야 합니다.
- 나가기를 눌러도 브라우저의 입력 초안은 지워지지 않습니다.
- '함께 저장'에서 브라우저가 두 번째 파일 내려받기를 막을 수 있습니다. 화면의 '다시 내려받기' 링크로 받을 수 있습니다.

### 모양 확인

- 합성 입력 8종·11쪽의 기존/새 PDF 비교: **사용자 승인 완료(2026-10-26)**.
- 실제 견적 예시 5종 비교: **모양 확인 대기**.

### 실제로 실행한 검사 (2026-10-26, macOS)

| 검사 | 결과 |
|---|---|
| `npm run lint` | 0 |
| `npm run typecheck` | 0 |
| `npm test` | 0 (기준 정답 비교·도메인·번호·가격표·PDF·Excel·API·화면 규칙·저장소 경계 포함. 실제 가격표 정답 비교 10개는 이 PC에 자료가 없어 건너뜀) |
| `npm run build` | 0 |
| `node tests/api/check-traces.mjs` | 0 (배포 번들에 변환 자료·글꼴·로고 포함, 원본·환경 변수 제외) |
| `node tests/api/http-smoke.mjs` | 0 (가짜 비밀번호로 입장·차단·조회·내려받기) |
| `node tests/ui/browser-smoke.mjs` | 0 (실제 Chromium으로 입장→랜딩→견적 작성, 5종 내려받기·번호 증가, 실패 시 번호 유지, 새로고침 복원, 휴대폰 화면, 나가기) |

**아직 실행하지 않은 검사**
- `vercel build --prod`: Vercel CLI 로그인과 프로젝트 연결이 필요해 아직 실행하지 않았습니다.
- 위 검사를 실행한 PC에는 맑은 고딕이 없어 임시 대체 글꼴로 확인했습니다. 실제 맑은 고딕으로 만든 ①②③ PDF는 배포 전에 다시 확인해야 합니다.
