# 사용 방법 (영업 담당자용)

## 1. 입장

1. 관리자에게 받은 주소를 엽니다.
2. 비밀번호를 입력하고 '입장'을 누릅니다.
3. 한 번 입장하면 **같은 브라우저에서는 30일 동안** 다시 묻지 않습니다.
   - 화면 오른쪽 위 '나가기'를 누르거나, 관리자가 비밀번호를 바꾸거나, 30일이 지나면 다시 입력합니다.
4. 처음 화면에서 **'견적서 작성'**을 누릅니다.

## 2. 견적서 만들기

1. **견적서 종류**를 고릅니다.

   | 종류 | 단가 기준 | 품목 고르는 곳 |
   |---|---|---|
   | ① 부가세 표시 | 부가세 별도. 합계에 부가세 10%를 더해 표시 | 출입통제 가격표 |
   | ② 부가세 미포함 | 부가세 별도. 부가세 없이 공급가액만 표시 | 출입통제 가격표 |
   | ③ 비용 분리 | 재료비·노무비·경비 각각 부가세 별도. 합계에 부가세 10% | 출입통제 가격표 |
   | ④ 영업1팀 제품 / ⑤ 영업2팀 제품 | 제품가격표의 부가세 포함 단가. 품목 합계 5천만 원 이상이면 2% 할인 | 제품가격표 |

2. **저장 형식**을 고릅니다: PDF, Excel, 또는 PDF + Excel 함께.
3. **작성자**를 고릅니다. 다른 사람 대신 작성해도 됩니다.
   - 휴대폰 번호를 고치면 견적서에 그 번호가 찍히고, **이 브라우저에서만** 다음에도 그 번호를 씁니다.
4. **거래처·견적 정보**를 입력합니다. 거래처와 견적 제목은 꼭 입력해야 합니다.
5. **품목**을 넣습니다.
   - ①②③: '출입통제 가격표에서 품목 선택'에서 소요군·검색으로 찾아 '선택 품목 추가'를 누릅니다. 추가한 뒤에는 모든 칸을 자유롭게 고칠 수 있습니다.
   - ④⑤: '엑셀 제품 불러오기'에서 모델명이나 품목명으로 검색해 '선택 제품을 품목에 추가'를 누릅니다.
     - 첫 제품을 넣으면 유효기간·납품·결제 조건과 참고사항이 그 제품 시트의 내용으로 채워집니다.
     - 제품 줄은 가격표와 **연동**되어 품목명·단가 등을 고칠 수 없습니다. 수량과 적용률만 고칩니다. 직접 고치려면 '연동 해제'를 누릅니다.
     - '복제'를 누르면 바로 아래에 같은 줄이 생깁니다.
   - '＋ 품목 추가'로 빈 줄을 만들어 직접 입력할 수도 있습니다. 품목은 최대 100개입니다.
   - **적용률**은 할인율의 반대입니다. 100%는 정상가, 90%는 10% 할인입니다. 계산에만 쓰고 견적서에는 나오지 않습니다.
   - ③에서는 재료비를 넣으면 노무비(재료비 × 281.25%)와 경비(노무비 × 3%)가 자동으로 계산됩니다. 직접 고친 칸은 그대로 두며, '자동으로 복원'을 누르면 다시 자동 계산합니다.
6. 화면 아래의 합계를 확인하고 **만들기** 버튼을 누릅니다.
7. 파일이 내려받아집니다. "견적서를 저장했습니다. NSFF0-…" 문구가 나오면 끝입니다.
   - PDF + Excel 함께 저장할 때 브라우저가 "여러 파일 다운로드" 허용을 물으면 허용을 누릅니다. 두 번째 파일이 받아지지 않았다면 문구 아래의 '다시 내려받기'를 누릅니다.

## 3. 견적번호

- 형식은 `NSFF0-작성일-일련번호`입니다. 작성일·작성자에 맞춰 자동으로 정해집니다.
- 번호 칸을 직접 고칠 수 있습니다. 이미 쓴 번호면 거부됩니다. 작성일이나 작성자를 바꾸면, 또는 '자동번호 적용'을 누르면 자동 번호로 돌아갑니다.
- **파일 만들기에 성공했을 때만** 번호를 사용한 것으로 칩니다. 실패하면 같은 번호를 다시 씁니다.
- PDF + Excel 함께 저장하면 두 파일이 같은 번호를 씁니다.
- 번호 이력은 **지금 쓰는 브라우저에만** 저장됩니다. 다른 PC나 다른 브라우저와는 번호가 겹칠 수 있으니, 여러 PC에서 쓸 때는 번호를 한 번 확인하세요.

## 4. 입력 내용 저장

- 입력한 내용은 바뀔 때마다 **이 브라우저에 자동 저장**됩니다. 창을 닫았다가 다시 열면 마지막 내용이 그대로 나옵니다.
- '입력내용 임시 저장'을 누르면 지금 내용을 따로 한 벌 저장합니다. '임시 저장 불러오기'로 그 내용을 다시 불러옵니다(지금 내용은 바뀝니다).
- 서버에는 아무것도 저장되지 않습니다. 만든 견적서 파일은 내 PC에 보관하세요.
- 공용 PC라면 사용 후 입력 내용을 지우고 '나가기'를 누르세요. 나가기만으로는 입력 초안이 지워지지 않습니다.

## 5. 이런 메시지가 나오면

| 메시지 | 할 일 |
|---|---|
| 거래처와 견적 제목을 입력하세요. | 거래처·견적 제목 칸을 채웁니다. |
| N번 수량은 양수(소수 셋째 자리까지), 단가는 0 이상의 정수로 입력하세요. | N번 줄의 수량·단가를 확인합니다. |
| 가격표가 바뀌어 다음 품목이 갱신되었습니다: … | 관리자가 가격표를 바꾼 것입니다. 바뀐 줄의 단가 등을 확인하고 만듭니다. |
| 엑셀에서 제품이 삭제되거나 이름이 변경되었습니다. 다시 선택하세요. | 그 줄을 지우고 제품을 다시 골라 넣습니다. |
| 이미 발급된 견적번호입니다. 다른 번호를 입력하세요. | 다른 번호를 넣거나 '자동번호 적용'을 누릅니다. |
| 입장이 필요합니다. 화면을 새로고침해 주세요. | 새로고침한 뒤 비밀번호를 다시 넣습니다. 입력 내용은 남아 있습니다. |
| 브라우저 자동 저장 실패 | 브라우저 저장 공간을 쓸 수 없는 상태입니다(사생활 보호 모드 등). 작업은 계속할 수 있지만 창을 닫으면 내용이 사라집니다. |
