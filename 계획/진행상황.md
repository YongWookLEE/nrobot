## 개발 환경 준비 (새 PC에서 이어받을 때)

1. Node 22, `npm install`.
2. `private/`를 채운다(git에 없음).
   - `private/prices/access.xlsx` ← `260730_출입통제 기준가격_06.xlsx`
   - `private/prices/catalog.xlsx` ← `(주)앤로보틱스_ 2026년도 견적서 양식.xlsx`
   - `private/fonts/malgun.ttf`, `malgunbd.ttf` ← `C:\Windows\Fonts`
   - `private/reference/` ← 기존 견적서 예시 5종(선택)
3. `.env`를 만든다(`cp .env.example .env` 후 실제 비밀번호·담당자 값). 원래 PC의 `.env`에 실제 값이 있다.
4. `npm run prepare-data && npm run dev`.
5. 기준 정답 재생성(필요할 때만)
   - Python 3.12 + `pip install reportlab==4.4.9 Pillow==12.3.0 pymupdf`
   - `python tools/golden/generate.py --legacy ../nrobot_full/web_quote/core`
   - 기존 코드 폴더가 옆에 있어야 한다.

## 알려진 문제·주의점

- **worktree 안에서는 Turbopack 빌드가 실패한다.** `node_modules`를 바로가기(junction)로 공유하면 생기는 문제라 worktree에서는 `npx next build --webpack`으로 확인하고, main에서는 정상 빌드된다.
- **입장 쿠키 서명 키는 `APP_PASSWORD` 자체다.** 쿠키가 유출되면 약한 비밀번호는 추측당할 수 있다. 비밀번호는 무작위로 길게 쓴다. 별도 비밀키 도입은 검토 사항이다.
- **`next start`를 http로 띄우면 브라우저가 쿠키를 저장하지 않는다.** 배포 환경에서 Secure 쿠키를 쓰기 때문이다. localhost는 예외다.
- **입장 비밀번호 미설정 시 응답 코드는 503이다.** spec은 '거부'만 정해 두었다.
- **EMF 사진 9장**: 내장 비트맵을 꺼내 쓰므로 원본과 픽셀이 약간 다를 수 있다(image73).
- **맑은 고딕 라이선스**: PDF에 내장하기로 회사가 판단했다. 정식 운영 전에 다시 검토한다.
- **견적번호는 브라우저별이라 PC끼리 겹칠 수 있다.** 나중에 DB로 교체한다.
- **사람 확인이 남아 있다.** 모양 비교 승인 전까지 '모양 확인 완료'로 기록하지 않는다.
